# SEO Playne

Обновлено 30 сентября 2026 года. Основной адрес: https://playne.ru/.

## Что сделано

- Восемь самостоятельных страниц с готовым HTML: главная, три игры, раздел правил и три статьи. Текст и ссылки доступны без выполнения JavaScript. Для самих игр JavaScript нужен.
- Индивидуальные title и description, русский язык документа, один H1, абсолютные canonical на HTTPS без www и без параметров.
- Open Graph и Twitter Card с названием, описанием и существующим логотипом Playne. Без вымышленных рейтингов и отзывов.
- JSON-LD: WebSite для названия сайта, CollectionPage для каталогов, WebPage и VideoGame для игр, Article для статей, BreadcrumbList для навигации.
- Автоматические `dist/sitemap.xml` и `dist/robots.txt`. Карта включает только восемь канонических страниц. Ресурсы CSS/JS открыты для обхода. Не выставляем фиктивную дату изменения при каждой сборке.
- Общие ссылки на игры и статьи в футере каждой страницы; из статей — переходы непосредственно к игре и оглавление.
- Постоянные редиректы с HTTP и www, со страниц без завершающего слеша и с явного `index.html`. Параметры рекламных ссылок сохраняются, canonical указывает адрес без параметров.
- Настоящий HTTP 404 для неизвестных адресов и собственная страница ошибки с `noindex`. Она не входит в sitemap.
- Новые страницы используют существующие цвета, темы и компактную мобильную шапку. Нет дополнительных внешних шрифтов или библиотек.
- Проверки SEO встроены в `npm run build`; CI после публикации сравнивает статьи и служебные файлы с собранными артефактами и проверяет редиректы/404.

## Страницы и их назначение

| URL | Содержание |
| --- | --- |
| `/` | Бесплатные небольшие браузерные игры, каталог Playne |
| `/naglaz/` | Игра на глазомер и сравнение размеров |
| `/circle/` | Нарисовать идеальный круг; собственная игра по мотивам Perfect Circle |
| `/colorfle/` | Угадывание смеси цветов; собственная игра по мотивам Colorfle |
| `/guides/` | Каталог правил и советов |
| `/guides/naglaz/` | Пропорции, измерения, результат и очки в «На глаз» |
| `/guides/perfect-circle/` | Один оборот, оценка окружности и причины незачтённой попытки |
| `/guides/colorfle/` | Доли 50/30/20, символы подсказок, пример хода и цифровое смешивание |

Статьи описывают именно реализацию Playne. Они не выдают сайт за авторов оригинальных игр. Нет обещаний медицинской пользы, «развития мозга» или гарантированной позиции в поиске.

## Как поддерживать

Метаданные и список индексируемых маршрутов находятся в `src/seo.ts`, статьи — в `src/guides.ts`. Компоненты `Site` и `GuidePage` используются и в браузере, и при подготовке HTML. `scripts/build-pages.mjs` создаёт страницы и карту сайта; `scripts/check-seo.mjs` проверяет итоговый `dist`, а не только исходники.

При добавлении игры или статьи:

1. Добавить маршрут и метаданные в `src/seo.ts`, компонент — в `src/Site.tsx` (статья из `guides.ts` подключится автоматически).
2. Добавить обычную ссылку из каталога и подходящего раздела сайта.
3. Разрешить новые точные пути в `.github/workflows/deploy-naglaz.yml` и `ops/naglaz/naglaz-deploy.sh`. Добавить редирект без слеша в `ops/naglaz/playne-domain.nginx.conf`.
4. Обновить серверный валидатор и nginx перед публикацией. Сохранить резервную копию, проверить `nginx -t`. Остальные проекты не затрагивать.
5. Выполнить `npm test` и `npm run build`, проверить страницу на телефоне и компьютере, затем результат деплоя.

`lastmod` необязателен и пока не указан. Если он понадобится, хранить реальную дату существенного обновления конкретной страницы, а не время запуска CI.

## Подключение кабинетов поисковиков

В рамках изменения не создавались свойства Google Search Console и Яндекс Вебмастера, права на них не подтверждались, sitemap через кабинеты не отправлялся. Яндекс Метрика уже работает, но это отдельный сервис и не подтверждает индексацию автоматически.

После подтверждения прав на `playne.ru` в кабинетах следует отправить:

https://playne.ru/sitemap.xml

В Google Search Console: «Файлы Sitemap», затем проверка главной и страниц игр через «Проверка URL». В Яндекс Вебмастере: добавить Sitemap и проверить важные страницы в инструментах индексации. При необходимости DNS-подтверждения использовать ровно выданную кабинетом TXT-запись.

Через несколько недель оценить индексируемые страницы, поисковые запросы, показы, клики и CTR. Для Core Web Vitals смотреть реальные данные посетителей, когда их станет достаточно; текущая работа не является замером полевых показателей. Индексация и позиции зависят от поисковиков — публикация sitemap сама по себе их не гарантирует.

## Основания

- [Google: JavaScript SEO](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics) — готовый HTML, понятные ссылки, метаданные и правильные HTTP-статусы.
- [Google: создание sitemap](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap) — канонические адреса и точные, а не автоматически обновляемые даты.
- [Google: канонические URL](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls) — согласованные canonical, карта сайта и редиректы.
