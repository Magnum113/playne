# Playne

Хаб браузерных игр для любопытных. Главная — `https://playne.ru/`, игра «На глаз» — `https://playne.ru/naglaz/`, «Круг» — `https://playne.ru/circle/`, «Оттенок» — `https://playne.ru/colorfle/`, «Где я?» — `https://playne.ru/geo/`, «Жми» — `https://playne.ru/pressure/`, «Одной линией» — `https://playne.ru/one-line/`. Светлая тема включена по умолчанию; кнопка в шапке переключает тему, выбор сохраняется в браузере.

Готовая игра в размеры. Пять раундов, 49 силуэтов и 94 сравнения. В каждой игре три сравнения высоты и два — длины; каждый объект появляется за партию только один раз. При повторной игре в открытой вкладке пары из предыдущей партии не выдаются снова.

## Публичная версия

Игра размещена по адресу https://playne.ru/naglaz/ без авторизации.
Исходный код и дальнейшая разработка находятся в
https://github.com/Magnum113/playne.
Серверные сборки находятся в отдельной папке `/srv/playne`, настройки сайта —
в отдельном конфиге Nginx `playne`. Устройство деплоя описано в
`ops/naglaz/README.md`.

## Запуск

Требуется Node.js 22.12+ или 24+.

```sh
npm install
npm run dev
```

Откройте адрес из терминала. При обычном запуске — http://localhost:5173. Чтобы открыть на телефоне в той же сети, используйте адрес Network из вывода Vite. Локальный сервер должен оставаться запущенным.

```sh
npm test
npm run build
npm run preview
```

На главной доступны «На глаз», «Круг», «Оттенок», «Где я?», «Жми» и «Одной линией». Логотип и описание генерации находятся в `BRAND.md`.

Сборка находится в `dist/` и подходит для статического хостинга в корне домена. «На глаз», «Круг» и «Оттенок» работают без внешних API. «Где я?» использует Maps JavaScript API. Общие рейтинги и вход через Яндекс обслуживает отдельный API и PostgreSQL; гостевой режим остаётся доступным.

## Проверка подключения Google Maps

Для географической игры есть локальная проверка карты и Street View без перемещения по улицам. Запуск: `npm run check:google`, затем `http://localhost:4173/`. Порт 4173 должен быть свободен. Введите ключ разработки, ограниченный Maps JavaScript API и адресом `http://localhost:4173/*`.

Ключ сохраняется в `.env.development.local` как `VITE_GOOGLE_MAPS_API_KEY`; файл исключён из Git и имеет права 600. Проверочный сервер слушает только локальный интерфейс, принимает сохранение только с собственного адреса и не выводит ключ в журнал. `scripts/google-check.html` и `scripts/google-check.mjs` не входят в публичную сборку. После сохранения ключа перезапустите Vite и откройте `/geo/`. Ключ сайта сохраняется отдельно в `.env.production.local`; в GitHub Actions используется секрет `PLAYNE_GOOGLE_MAPS_API_KEY`.

## Игра

- Во всех сравнениях объекты стоят рядом по горизонтали на общей линии: ориентир слева, изменяемый объект справа. Это относится и к высоте, и к длине.
- Бирюзовый объект — ориентир, его размер известен.
- Сиреневый объект можно перемещать и растягивать за угловой маркер.
- Размер также меняется ползунком, кнопками «−» и «+» и клавиатурой.
- После проверки светлый силуэт плавно переходит к правильному масштабу, а сиреневая оценка игрока остаётся для сравнения. Общий масштаб сцены плавно подстраивается; очки набираются в левом верхнем углу поля. Следующий раунд доступен после анимации (около 1,15 секунды). При включённом уменьшении движения ответ появляется сразу.
- Названия объектов подписаны непосредственно под силуэтами. После проверки показаны две подписи с метрами: «Твой размер» и «Правильный». Сиреневая сплошная размерная линия относится к оценке, светлая пунктирная — к ответу.
- В результате варианты выравниваются по левому краю и основанию. Узкие башни и ракеты слегка разнесены по горизонтали, чтобы меньший силуэт не терялся внутри большего. Масштаб размеров остаётся общим для всей сцены.
- Лучший результат сохраняется в браузере. Перезагрузка завершает текущую игру.

## Круг

Нарисуй круг вокруг точки одним движением мыши, пальца или пера. После отпускания показываются точность и пунктирный идеальный круг с тем же средним радиусом. Можно сразу рисовать следующую попытку или нажать «Ещё раз». Escape очищает поле.

Оценка использует отклонение радиуса от среднего относительно фиксированной центральной точки. Линия пересчитывается в 361 равноудалённую по длине точку, чтобы скорость устройства и частота событий не меняли оценку. Незамкнутые дуги, несколько оборотов, проход через центр и сильные возвраты не засчитываются. Небольшой разрыв и возвраты снижают оценку. Минимальный радиус — 45 из 600 единиц поля.

Рекорд хранится отдельно от «На глаз», в ключе `playne:circle:v1`. При недоступном хранилище игра продолжает работать. Код: `src/CircleGame.tsx`, `src/circle.ts`, `src/circle.css`. Проверки геометрии и хранения: `tests/circle.test.ts`.

## Оттенок

Игра на подбор цвета: образец и выбранный оттенок стоят рядом, цвет выбирается на непрерывной палитре и ползунке тона. Пять раундов, до 500 очков; партия и рекорд сохраняются локально. После игры можно начать новую. Полные правила, экраны и расчёты описаны в [COLORFLE_GAME.md](COLORFLE_GAME.md).

## Где я?

Пять мест в пяти разных частях света. Вращай панораму Google Street View, поставь точку на карте и проверь ответ. Перемещение между панорамами отключено. До 250 метров — 100 очков, за пять раундов — до 500. Показаны правильное место, расстояние и обе точки на карте. Рекорд и последние локации хранятся в браузере, недавно сыгранные места пропускаются при подборе новой партии. На телефоне карта открывается поверх панорамы.

Каталог содержит 100 визуально проверенных наружных локаций. Панорамы загружаются непосредственно из Google, фотографии и тайлы не копируются в проект. Код, настройка ключей и события Метрики описаны в [GEO_GAME.md](GEO_GAME.md).

## Жми

`/pressure/` — игра по мотивам Pressing Under Pressure: одна кнопка, 30 случайных уровней, первая ошибка завершает попытку. 20 семейств заданий: счёт, математика, логика, память, ожидание, сигнал, удержание и двойное нажатие. Меняются порядок, числа, символы, слова и временные окна. Новая подборка учитывает предыдущие партии.

Управление: мышь, касание, пробел или Enter. Автоповтор клавиши и дополнительные пальцы не считаются нажатиями. При потере фокуса — пауза с перезапуском текущего уровня. Рекорд хранится в `playne:pressure:v1`; при доступном API сервер выдаёт задания и проверяет журнал нажатий. Авторизованные результаты публикуются сразу после завершения, у гостей доступно сохранение после входа. Отдельный рейтинг — `/leaderboard/?game=pressure`, результат — уровни из 30.

Код: `src/pressure.ts`, `src/PressureGame.tsx`, `src/pressure.css`. Правила и источники: [PRESSURE_GAME.md](PRESSURE_GAME.md).

## Одной линией

`/one-line/` — головоломка: соедини числа по порядку и пройди каждую клетку один раз, не пересекая стенки и свой маршрут. Пять полей от 4 × 4 до 6 × 6, до 500 очков. За решение поля — 80 очков и до 20 за скорость; подсказка стоит 15 очков, отмена и перезапуск поля бесплатны.

В режиме «Задача дня» — общие поля на московскую дату и первая дневная попытка для рейтинга. «Практика» отделена от дневного и общего рейтингов. Незавершённая партия продолжается в том же браузере. Правила, устройство страниц и источник механики: [LINE_GAME.md](LINE_GAME.md).

## Контент

Двенадцать иллюстраций построены векторным кодом, включая секвойю Генерал Шерман, Статую Единства, МКС и гигантского кальмара. Ещё 37 — растровые силуэты в `public/art/`. PNG уменьшены и сохранены в оттенках серого: это сохраняет форму контура. Изображения подгружаются уже на экране правил, чтобы первый раунд не начинался с пустого силуэта; внешние сервисы для показа не требуются. Контуры стилизованы; вычисления используют проверяемый габарит по заданной оси. Это игровые иллюстрации, а не технические чертежи.

20 октября 2026 года добавлены 30 объектов и 60 сравнений: от императорского пингвина и марсохода до Бурдж-Халифы и супертанкера Seawise Giant. У каждого нового объекта есть собственная PNG-иллюстрация, проверяемый размер и не менее двух сравнений; каждый доступен как объект для угадывания. Выбор моделей, границ измерения и источники описаны в [NAGLAZ_CONTENT_2026_10.md](NAGLAZ_CONTENT_2026_10.md).

Рисунки используют собственные координаты по габаритам объекта и единый коэффициент масштаба по обеим осям. Круглые детали не превращаются в овалы при изменении размера и показе ответа. Для визуальной проверки всех рисунков есть галерея: `npx tsx scripts/render-artwork.tsx`, затем откройте `/artifacts/artwork-review.html` на сервере разработки.

Размеры, уточнения и ссылки на источники находятся в `src/data.ts`, список источников — в `SOURCES.md`. У пирамиды берётся первоначальная высота, у Статуи Свободы — высота вместе с пьедесталом, у Falcon 9 — конфигурация со стандартным обтекателем.

## Код

- `src/Hub.tsx` — главная, каталог игр и ответы на вопросы.
- `src/SiteHeader.tsx`, `src/theme.ts` — бренд, переключение и сохранение темы.
- `scripts/build-pages.mjs` — статические страницы игр, включая `/one-line/`, справка, рейтинг и главная с собственными метаданными.
- `src/App.tsx` — экраны, раунды, результаты, помощь.
- `src/Board.tsx` — сцена, масштабирование, перемещение и касания.
- `src/resultLayout.ts` — размещение и общий масштаб результата с местом для размерных линий.
- `src/Silhouette.tsx` — выбор векторного или растрового силуэта.
- `src/RasterSilhouette.tsx`, `src/artwork.ts` — окрашивание PNG, кадрирование и пропорции новых иллюстраций.
- `src/data.ts` — каталог, сравнения и подбор пяти разных целей.
- `src/game.ts` — очки, форматирование и локальный рекорд.
- `src/analytics.ts` — счётчик и цели Яндекс Метрики.
- `src/GeoGame.tsx`, `src/geo.ts`, `src/googleMaps.ts`, `src/geoLocations.ts` — географическая игра.
- `src/style.css` — общие стили и светлая/тёмная темы.
- `tests/game.test.ts` — расчёты, подборки и устойчивость хранения.

SVG использует единую шкалу метров для обоих объектов. Она постоянна внутри раунда; адаптация экрана меняет отображение обоих объектов одинаково. Перемещение не влияет на оценку. Правильный ответ доступен в коде клиента — для игры без общего рейтинга это намеренное упрощение.

Список целей Метрики, их идентификаторы и параметры находится в `ANALYTICS.md`.

## Проверка

Автоматические тесты проверяют формулу очков, допустимые размеры, отсутствие повторов любых объектов и зеркальных пар, а также работу без доступного хранилища. Ручная проверка в браузере включает полное прохождение, изменение размера за угол, ползунок, окно правил, повторную игру и узкий экран. Проверка на физическом телефоне отдельно не выполнялась.

Для повторной проверки крайних оценок откройте `/artifacts/result-review.html` на сервере разработки. Там можно выбрать любую пару и отношение размеров, затем запустить обычную анимацию ответа. Тесты `tests/resultLayout.test.ts` проверяют границы сцены для всех пар, крайних и точных ответов на двух ширинах.

Для животных в подписях указан выбранный типичный, крупный или рекордный экземпляр. У кольца оценивается высота обода, а не всей стойки. Открытые до обновления вкладки получают от API исходные 34 сравнения; актуальный клиент передаёт поддерживаемые идентификаторы пар и получает полный каталог.

## Аккаунты и рейтинг

Вход через Яндекс ID, смена ника, история и отдельные рейтинги шести игр. Общий зачёт даёт до 1000 баллов за каждую игру, до 6000 в сумме. В «Одной линией» в общий зачёт входит лучший дневной результат режима «Задача дня»; «Практика» имеет отдельный рейтинг. Для остальных игр берётся лучший результат среди режимов. Серверная архитектура, настройка, защита результатов, тесты, деплой и резервные копии описаны в [AUTH_LEADERBOARD.md](AUTH_LEADERBOARD.md).
