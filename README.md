# Playne

Хаб небольших игр в браузере. Главная — `https://playne.ru/`, игра «На глаз» — `https://playne.ru/naglaz/`, «Круг» — `https://playne.ru/circle/`. Светлая тема включена по умолчанию; кнопка в шапке переключает тему, выбор сохраняется в браузере.

Готовый MVP игры в размеры. Пять раундов, 14 силуэтов и 22 сравнения. В каждой игре три сравнения высоты и два — длины; угадываемые объекты не повторяются.

## Публичная версия

Игра размещена по адресу https://playne.ru/naglaz/ без авторизации.
Исходный код и дальнейшая разработка находятся в
https://github.com/Magnum113/playne.
Серверные сборки находятся в отдельной папке `/srv/playne`, настройки сайта —
в отдельном конфиге Nginx `playne`. Устройство деплоя описано в
`ops/naglaz/README.md`.

## Запуск

Требуется Node.js 22.12+ или 24+.

```sh
npm install
npm run dev
```

Откройте адрес из терминала. При обычном запуске — http://localhost:5173. Чтобы открыть на телефоне в той же сети, используйте адрес Network из вывода Vite. Локальный сервер должен оставаться запущенным.

```sh
npm test
npm run build
npm run preview
```

Главная содержит одну доступную игру и два анонса «Скоро», без неработающих кнопок. Логотип и описание генерации находятся в `BRAND.md`.

Сборка находится в `dist/` и подходит для статического хостинга в корне домена. Внешних API, ключей и базы данных нет.

## Игра

- Во всех сравнениях объекты стоят рядом по горизонтали на общей линии: ориентир слева, изменяемый объект справа. Это относится и к высоте, и к длине.
- Бирюзовый объект — ориентир, его размер известен.
- Сиреневый объект можно перемещать и растягивать за угловой маркер.
- Размер также меняется ползунком, кнопками «−» и «+» и клавиатурой.
- После проверки светлый силуэт плавно переходит к правильному масштабу, а сиреневая оценка игрока остаётся для сравнения. Общий масштаб сцены плавно подстраивается; очки набираются в левом верхнем углу поля. Следующий раунд доступен после анимации (около 1,15 секунды). При включённом уменьшении движения ответ появляется сразу.
- Названия объектов подписаны непосредственно под силуэтами. После проверки показаны две подписи с метрами: «Твой размер» и «Правильный». Сиреневая сплошная размерная линия относится к оценке, светлая пунктирная — к ответу.
- В результате варианты выравниваются по левому краю и основанию. Узкие башни и ракеты слегка разнесены по горизонтали, чтобы меньший силуэт не терялся внутри большего. Масштаб размеров остаётся общим для всей сцены.
- Лучший результат сохраняется в браузере. Перезагрузка завершает текущую игру.

## Круг

Нарисуй круг вокруг точки одним движением мыши, пальца или пера. После отпускания показываются точность и пунктирный идеальный круг с тем же средним радиусом. Можно сразу рисовать следующую попытку или нажать «Ещё раз». Escape очищает поле.

Оценка использует отклонение радиуса от среднего относительно фиксированной центральной точки. Линия пересчитывается в 361 равноудалённую по длине точку, чтобы скорость устройства и частота событий не меняли оценку. Незамкнутые дуги, несколько оборотов, проход через центр и сильные возвраты не засчитываются. Небольшой разрыв и возвраты снижают оценку. Минимальный радиус — 45 из 600 единиц поля.

Рекорд хранится отдельно от «На глаз», в ключе `playne:circle:v1`. При недоступном хранилище игра продолжает работать. Код: `src/CircleGame.tsx`, `src/circle.ts`, `src/circle.css`. Проверки геометрии и хранения: `tests/circle.test.ts`.

## Контент

Восемь исходных иллюстраций построены векторным кодом. Ещё шесть — сгенерированные силуэты: кит, тираннозавр, автобус, жираф, слон и баскетбольная стойка. PNG хранятся внутри проекта в `public/art/`; внешние сервисы для показа не требуются. Контуры стилизованы; вычисления используют проверяемый габарит по заданной оси. Это игровые иллюстрации, а не технические чертежи.

Рисунки используют собственные координаты по габаритам объекта и единый коэффициент масштаба по обеим осям. Круглые детали не превращаются в овалы при изменении размера и показе ответа. Для визуальной проверки всех рисунков есть галерея: `npx tsx scripts/render-artwork.tsx`, затем откройте `/artifacts/artwork-review.html` на сервере разработки.

Размеры, уточнения и ссылки на источники находятся в `src/data.ts`, список источников — в `SOURCES.md`. У пирамиды берётся первоначальная высота, у Статуи Свободы — высота вместе с пьедесталом, у Falcon 9 — конфигурация со стандартным обтекателем.

## Код

- `src/Hub.tsx` — главная, каталог игр и ответы на вопросы.
- `src/SiteHeader.tsx`, `src/theme.ts` — бренд, переключение и сохранение темы.
- `scripts/build-pages.mjs` — статические страницы `/naglaz/` и `/circle/` с собственными метаданными и предварительно отрисованная главная.
- `src/App.tsx` — экраны, раунды, результаты, помощь.
- `src/Board.tsx` — сцена, масштабирование, перемещение и касания.
- `src/resultLayout.ts` — размещение и общий масштаб результата с местом для размерных линий.
- `src/Silhouette.tsx` — выбор векторного или растрового силуэта.
- `src/RasterSilhouette.tsx`, `src/artwork.ts` — окрашивание PNG, кадрирование и пропорции новых иллюстраций.
- `src/data.ts` — каталог, сравнения и подбор пяти разных целей.
- `src/game.ts` — очки, форматирование и локальный рекорд.
- `src/analytics.ts` — счётчик и цели Яндекс Метрики.
- `src/style.css` — адаптивная тёмная тема.
- `tests/game.test.ts` — расчёты, подборки и устойчивость хранения.

SVG использует единую шкалу метров для обоих объектов. Она постоянна внутри раунда; адаптация экрана меняет отображение обоих объектов одинаково. Перемещение не влияет на оценку. Правильный ответ доступен в коде клиента — для игры без общего рейтинга это намеренное упрощение.

Список целей Метрики, их идентификаторы и параметры находится в `ANALYTICS.md`.

## Проверка

Автоматические тесты проверяют формулу очков, допустимые размеры, отсутствие повторов целей и работу без доступного хранилища. Ручная проверка в браузере включает полное прохождение, изменение размера за угол, ползунок, окно правил, повторную игру и узкий экран. Проверка на физическом телефоне отдельно не выполнялась.

Для повторной проверки крайних оценок откройте `/artifacts/result-review.html` на сервере разработки. Там можно выбрать любую пару и отношение размеров, затем запустить обычную анимацию ответа. Тесты `tests/resultLayout.test.ts` проверяют границы сцены для всех пар, крайних и точных ответов на двух ширинах.

Новые пары: кит и самолёт, тираннозавр и кит, автобус и кит, тираннозавр и автобус, кит и футбольное поле; слон и жираф в двух направлениях, кольцо и жираф, кольцо и слон в двух направлениях. Для животных в подписях указан выбранный типичный или крупный экземпляр. У кольца оценивается высота обода, а не всей стойки.
